# 🦁 英语乐园 · English Learn

> 面向深圳小学 1-2 年级小朋友的英语互动学习网页应用，基于沪教版（牛津深圳版）教材

一个**纯静态、单文件 HTML** 的英语互动教学 App。包含 5 大模块、16 个互动游戏、覆盖 26 个字母、86 个主题单词、69 个生活句子，所有数据内嵌、零依赖、离线可用。打开网页就能用，电脑、平板、手机都能玩。

---

## ✨ 特性

- 🔤 **字母乐园**：26 个字母大小写、单词、emoji 配对，配对/排序/找字母 3 个游戏
- 📚 **单词冒险**：10 个主题 86 个单词（问候/数字/颜色/家庭/动物/身体/食物/学校/动作/形状），英中配对/拼写/听音选词 3 个游戏
- 💬 **句子达人**：9 个场景 69 个常用句型，句子排序/选择填空/听句选译 3 个游戏
- 👂 **听力挑战**：听单词/听字母/听句子 3 种模式
- 🎮 **趣味游戏**：记忆翻牌/打地鼠/限时挑战 3 个综合游戏
- 🔊 **女声优先 TTS**：自动挑选系统最甜美的英语女声
- 🎵 **无需音频文件**：用 Web Audio API 振荡器生成答对/答错/点击音效
- ⭐ **星星奖励系统**：每答对一题都加星，刷新页面不丢
- 📱 **移动端友好**：手机/平板/电脑自适应，44px 触控热区
- 🔒 **零依赖零追踪**：不收集任何数据，无外部 CDN

## 🚀 快速开始

### 本地预览

**Mac / Linux**：

```bash
cd english-learn
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

**Windows (PowerShell)**：

```powershell
cd english-learn
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

**或者直接双击 `index.html`** —— 也可以跑（不过部分浏览器在 `file://` 协议下会限制本地存储和音频自动播放，建议起本地 server）。

### 部署到 GitHub Pages（推荐，多终端访问）

1. 在 GitHub 上创建一个新仓库（如 `english-learn`）
2. 把 `index.html` 和 `README.md` 提交到 `main` 分支
3. 进入仓库 **Settings → Pages**
4. **Source** 选择 `Deploy from a branch`，**Branch** 选 `main`，目录选 `/ (root)`
5. 等 1-2 分钟，GitHub 会给你一个链接，形如：

   ```
   https://<你的GitHub用户名>.github.io/english-learn/
   ```

6. **任何终端**（电脑/平板/手机）只要打开这个链接就能玩 ✅
7. （可选）绑定自定义域名：在 Pages 设置的 **Custom domain** 里填入你的域名，按指引配置 DNS

## 🛠 技术栈

| 层面 | 方案 |
|------|------|
| HTML | 原生 HTML5（单文件） |
| CSS | 原生 CSS3（内嵌，含响应式断点） |
| JavaScript | 原生 ES6（内嵌，零依赖） |
| 语音合成 | 浏览器内置 Web Speech API |

| 数据持久化 | `localStorage`（星星数 + 已学单词） |
| 部署 | 任意静态文件服务（GitHub Pages / Vercel / Netlify / Nginx） |

**没有任何 npm / 构建步骤 / 外部 CDN。** 复制 `index.html` 到任何能托管静态文件的地方，都能跑。

## 🔒 数据与隐私

- 所有学习进度（星星数、已学单词）仅保存在你**当前浏览器**的 `localStorage` 里
- 不向任何服务器发送任何数据
- 不使用任何 Cookie、不使用任何追踪脚本
- 换浏览器、清缓存、隐私模式下数据不会保留——这是设计上的取舍（保护小朋友隐私）
- 不支持多设备数据同步（如果你需要这个功能，告诉我，未来可以加）

## 🌐 浏览器兼容性

| 浏览器 | 最低版本 | 状态 |
|--------|----------|------|
| Chrome | 90+ | ✅ 完整支持 |
| Edge | 90+ | ✅ 完整支持 |
| Safari (macOS) | 14+ | ✅ 完整支持（推荐使用，女声最佳） |
| Safari (iOS) | 14+ | ✅ 完整支持（首次播放声音需点击屏幕） |
| Firefox | 90+ | ⚠️ 语音功能依赖系统语音包，效果可能不如 Chrome/Safari |
| 安卓 Chrome | 90+ | ⚠️ **发音受限**：国内网络下 Web Speech 默认走 Google 在线 TTS，会静默失败；代码已加超时检测 + Toast 提示。建议换用 iOS Safari 或 macOS Safari 获得最佳体验 |
| 安卓 Edge / Firefox | - | 同上，受限 |
| 微信内置浏览器 | - | ⚠️ 受限，建议「在浏览器中打开」 |

> 💡 **关于发音的说明**：纯静态 HTML 用的是浏览器内置 Web Speech API，**没有任何后端 TTS 服务**。iOS/macOS Safari 自带本地英语语音（macOS 的 Samantha 是最甜美的女声）；安卓 Chrome 国内网络下会因 Google TTS 连不上而静默失败。代码会在 1.5 秒内检测到这种情况并给出 Toast 提示，但**声音不会变出来**——这是浏览器+网络层面的限制，纯前端无法绕过。如果需要安卓上 100% 能发音，需要加后端调用国内 TTS（讯飞/百度/腾讯），但目前本项目不包含这个后端。
